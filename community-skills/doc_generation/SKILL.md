# doc_generation

在需要产出技术文档、实施说明、部署文档、交付文档时使用本技能。

## 文档类型

- README
- 接口文档
- 部署手册
- 使用说明
- 变更说明
- 运维手册
- 项目交付文档

## 写作流程

1. 先识别目标读者
   - 开发者
   - 运维
   - 管理者
   - 最终用户
2. 明确文档目标
   - 教会别人做什么
   - 解释为什么这样做
   - 记录当前状态与边界
3. 组织结构
   - 背景 / 目标
   - 前置条件
   - 步骤
   - 示例
   - 常见问题
   - 风险 / 注意事项
4. 写法要求
   - 先结论后展开
   - 步骤可执行
   - 术语前后一致
   - 对关键路径给示例

## 输出格式

### 文档正文
按适合场景的层级输出，优先保证可读性与可执行性。

### 补充内容
按需附上：
- 命令示例
- 配置样例
- 输入输出示例
- FAQ
- 验收清单

## 质量标准

- 别写成空泛宣传稿
- 看完后别人应该能照着做
- 避免隐藏前提条件
- 如果有不确定内容，要单独标记“待确认”
