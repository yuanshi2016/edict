# data_analysis

在需要分析表格、报表、日志、业务数据时使用本技能。

## 目标

把“数据堆”变成：
- 明确结论
- 关键指标
- 变化原因
- 可执行建议

## 分析流程

1. 明确问题
   - 要回答什么业务问题
   - 成功标准是什么
2. 理解数据
   - 字段含义
   - 时间范围
   - 缺失值 / 异常值
   - 样本量是否足够
3. 建立指标
   - 总量
   - 均值 / 中位数
   - 环比 / 同比
   - 转化率 / 留存 / 占比
4. 发现模式
   - 趋势
   - 分层差异
   - 异常波动
   - 相关性线索
5. 提炼结论
   - 先说发生了什么
   - 再说为什么可能发生
   - 最后说建议做什么

## 输出格式

### 一页结论
- 3~5 条最重要结论

### 关键指标
- 指标名
- 当前值
- 变化情况
- 解读

### 异常与原因假设
- 哪些点异常
- 可能原因
- 还需要什么补充数据

### 建议动作
- 立刻可做的动作
- 需要进一步验证的动作

## 原则

- 数据不足时不要装确定
- 结论必须对应数据现象
- 区分“事实”“解释”“建议”
- 如果适合可补充图表建议，但文字结论优先
