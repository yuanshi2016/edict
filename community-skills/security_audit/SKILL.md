# security_audit

在需要做安全审计、上线前风险检查、敏感系统排查时使用本技能。

## 审计范围

- 身份认证与授权
- 输入校验与输出编码
- 文件读写与路径安全
- 密钥、令牌、凭证管理
- 第三方依赖与供应链风险
- 日志、审计、敏感信息暴露
- 网络边界、管理接口、调试入口

## 审计步骤

1. 识别资产
   - 有哪些敏感数据
   - 哪些接口可被外部访问
2. 识别攻击面
   - Web API
   - 文件上传
   - 管理后台
   - 定时任务
   - Webhook / 回调
3. 检查常见高危问题
   - 注入（SQL / 命令 / 模板）
   - SSRF
   - 路径遍历
   - 任意文件读写
   - 权限绕过
   - 弱鉴权 / 弱口令 / 默认凭证
   - 敏感信息硬编码
4. 评估影响
   - 数据泄露
   - 远程执行
   - 账户接管
   - 横向移动
5. 给出修复建议
   - 先给止血方案
   - 再给长期治理建议

## 输出格式

### 审计结论
- 总体风险：高 / 中 / 低
- 最关键的 1~3 个风险点

### 风险清单
每项包含：
- 风险名称
- 位置 / 触发面
- 利用条件
- 影响范围
- 修复建议

### 修复优先级
- P0：必须立即处理
- P1：本轮上线前处理
- P2：纳入后续整改

## 注意事项

- 不要用空泛措辞，要指出具体点位
- 无法验证的风险要标记为“待确认”
- 如果没有明显漏洞，也要说明已检查的范围与结论
